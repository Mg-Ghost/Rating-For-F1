# 🏎️ Rating For F1

REST API сервер на Go для получения рейтинговых данных Формулы 1: гонщики, топ-15, команды и трассы.

## 📋 Описание

**Rating For F1** — это backend-сервис, предоставляющий данные о гонщиках, командах и трассах Формулы 1 через HTTP API. Данные хранятся в базе данных PostgreSQL.

## 🛠️ Технологии

- **Язык:** Go
- **База данных:** PostgreSQL (`lib/pq`)
- **Архитектура:** REST API (стандартная библиотека `net/http`)

## 📁 Структура проекта

```
Rating-For-F1/
├── main.go           # Точка входа, регистрация маршрутов
├── database/         # Инициализация и управление БД
├── models/           # Модели данных
├── parser/           # Парсинг данных
├── Racers/           # Логика для гонщиков
├── Top15Racers/      # Логика для топ-15 гонщиков
├── TeamsF1/          # Логика для команд Ф1
├── Highway/          # Логика для трасс
├── go.mod
└── go.sum
```

## 🚀 Запуск

### Предварительные требования

- Go 1.18+
- PostgreSQL

### Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/Mg-Ghost/Rating-For-F1.git
cd Rating-For-F1

# Установить зависимости
go mod download

# Запустить сервер
go run main.go
```

Сервер запустится на `http://localhost:8182`.

> ⚠️ Убедитесь, что PostgreSQL запущен и настроен до старта сервера. Параметры подключения задаются в пакете `database`.

## 📡 API Эндпоинты

Все эндпоинты поддерживают только метод **GET**.

### Гонщики

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/racers` | Получить список всех гонщиков |
| GET | `/racers/{id}` | Получить гонщика по ID |

### Топ-15 гонщиков

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/Topracers` | Получить топ-15 гонщиков |
| GET | `/Topracers/{id}` | Получить гонщика из топ-15 по ID |

### Команды

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/teams` | Получить список всех команд |
| GET | `/teams/{id}` | Получить команду по ID |

### Трассы

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/highway` | Получить список всех трасс |
| GET | `/highway/{id}` | Получить трассу по ID |
